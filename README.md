# Marvel Landing

Учебный фан-лендинг Marvel с одной кнопкой сбора Мстителей.

## Как открыть

Открой index.html в браузере.

## Файлы

- index.html — структура страницы.
- style.css — оформление.
- script.js — поведение кнопки.
